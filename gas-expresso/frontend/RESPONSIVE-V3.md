# Gás Expresso — Responsive UX/UI V3

## Objetivo
Refinamento mobile-first da navegação e das páginas **Minha conta** e **Rastrear**, mantendo o Design System existente.

## Alterações
- Header mobile com botão de menu e painel lateral compacto.
- Navegação móvel com links para Início, Pedir gás, Rastrear, Minha conta e Áreas profissionais.
- Bloqueio do scroll do `body` enquanto o menu está aberto.
- Áreas de toque ampliadas para botões e links.
- Ajuste de hierarquia e espaçamento da página Minha conta em ecrãs pequenos.
- Ajuste do mapa, progresso, timeline e cartões da página Rastrear.
- Compatibilidade com telas muito pequenas (até 380px).
- Bottom navigation mantido como acesso persistente às funções principais.

## Validação
A instalação de dependências com `npm install` excedeu o tempo disponível no ambiente de trabalho desta entrega. Validar localmente com:

```powershell
npm install
npm run build
npm run dev
```
