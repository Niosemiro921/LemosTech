# Gás Expresso Frontend 4.0.0

Frontend React/Vite alinhado ao backend 2.0.0.

## Perfis
- Cliente: criação, pedidos, rastreamento e chat com o profissional.
- Entregador: operação mobile-first, GPS, ofertas, carteira, ganhos, documentos e incidentes.
- Prestador: perfil profissional completo, veículo CAR/MOTORCYCLE, carteira e operação.
- Fornecedor: perfil comercial, ERP/CRM e operações de empresa.
- Admin: dashboard, candidaturas, parceiros, pedidos, dispatch, auditoria, carteira e email.

## Contrato
`VITE_API_BASE_URL=http://localhost:5048/api/v1`
`VITE_REALTIME_URL=` pode ficar vazio; a aplicação usa o host da API e SSE por defeito.
