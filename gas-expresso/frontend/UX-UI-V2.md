# Gás Expresso — UX/UI V2: Minha Conta + Rastrear

## Minha conta
A página foi reorganizada como um dashboard de cliente, com identidade da conta, status, métricas, atalhos de ação, pedido recente e dados da conta.

## Rastrear
A página agora usa uma composição operacional: cabeçalho de estado, barra de progresso, mapa grande, localização, cartão do entregador, resumo financeiro, timeline e ações finais.

## Regra de produto
O rastreamento continua com dados simulados na V1. O backend deverá substituir esses dados por eventos reais de dispatch/WebSocket.
